This is my website for 2026-2027. It is a more thorough version of my website from 2025-2026, showcasing my research and teaching in more detail (and in a more readable, user-friendly design). The drop-down boxes have been replaced with a card-grid structure that mirrors Instagram, and the font has been updated to two versions—serif for headings and sans-serif for the body text. The digital humanities page is more playful than the rest, reflecting the virtual experimentation and sci-fi culture shaping that field. As you can see, the majority of the website is built using HTML/CSS (and updated using Git), though it operates with the same sophistication as a CMS platform such as SquareSpace or WordPress. The files for this website can be copied and forked to your own GitHub repository if you would like to make your own personal website.
